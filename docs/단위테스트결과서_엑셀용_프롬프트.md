# 단위테스트 결과서 — ChatGPT용 (한 시트 · 엑셀 붙여넣기)

ChatGPT는 이 저장소를 **모릅니다.** 먼저 **프로젝트 맥락**을 붙인 뒤, **작성 지시**를 붙이세요.

---

## 1단계 — 맥락 만들기 (로컬 / Cursor 터미널)

```bash
cd /home/ec2-user/JHproject
bash scripts/export-unit-test-context.sh > /tmp/jhproject-context.txt
```

필요하면 `prisma/schema.prisma` 일부나 특정 파일 내용을 `context.txt` 맨 아래에 수동 추가.

---

## 2단계 — ChatGPT에 한 번에 붙여넣기

**순서:** (① 맥락 전체) + (② 아래 BEGIN~END 프롬프트)

---

### ① 프로젝트 맥락 (여기에 /tmp/jhproject-context.txt 내용 붙여넣기)

```
[여기 비우면 안 됨 — context.txt 내용 붙여넣기]
```

---

### ② 작성 지시 (복사)

```
---BEGIN---

당신은 SI QA입니다. 위 [프로젝트 맥락]만 근거로 **단위테스트 결과서(평가표)** 를 작성하세요.

## 맥락 없으면
맥락이 비었거나 API/ lib 목록이 없으면 **본문 작성하지 말고** 필요 자료 3줄만 안내하세요.

## 출력 (Excel 1시트용)
- **시트 1개만.** 표지·요약·다른 시트 금지.
- **마크다운·설명 문단·코드블록 금지.**
- **첫 줄 = 헤더**, **2줄부터 = 데이터**.
- 열 구분은 **탭(Tab)만**. 콤마 구분 금지.
- **최소 50행**, 권장 60~80행 (헤더 제외).
- 맥락에 없는 API·함수·파일 경로 **금지**.

## 헤더 (이 순서 그대로, 탭 구분)
TC_ID	대분류	기능	단위대상(함수/API)	소스경로	테스트조건	입력	기대결과	실제결과	판정	실행일	비고

## TC_ID
UT-AUTH-001 형식. 대분류 코드: AUTH, PRD, BLD, ORD, PAY, CRT, ADM, UTL

## 판정
P / F / B / N 중 하나. 맥락만으로 실행 불가하면 **N**, 비고에 "수동 검증 필요".

## 대분류 균형
맥락의 API·lib에 맞춰 분배. 맥락에 있는 route마다 최소 1건(가능하면 정상+오류 2건).

## 작성 후
맨 마지막 줄에만 한 줄 허용:
`#TOTAL_ROWS=<데이터행수>`

**지금 위 규칙으로 탭 구분 데이터만 출력하세요. 첫 줄은 헤더.**

---END---
```

---

## 3단계 — Excel

1. ChatGPT 답변 **전체 복사** (헤더부터 `#TOTAL_ROWS` 전까지)
2. Excel 빈 시트 → A1 붙여넣기
3. 안 나뉘면: 데이터 → 텍스트 나누기 → 구분 기호 **탭**

---

## 왜 이렇게 나눴나

| 문제 | 해결 |
|------|------|
| ChatGPT가 repo 모름 | `export-unit-test-context.sh` 덤프 필수 |
| 표지/요약 시트 필요 없음 | **한 시트 평가표**만 |
| 복붙하면 엑셀 | 탭만, 헤더 1줄 + 데이터 |

프로젝트가 바뀌면 **1단계 스크립트 다시 실행** → 맥락 갱신 → ChatGPT 재요청.
