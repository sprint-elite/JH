# Part A — 고객(사용자) 매뉴얼

## A.1 시작하기

### A.1.1 이 사이트로 할 수 있는 일

- **반팔티·카라티·후드·맨투맨** 등 단체복 상품을 카테고리에서 고릅니다.
- **나염 빌더**에서 로고·문구를 올려 앞·뒷면 시안을 만듭니다.
- 수량·옵션(사이즈, 인쇄면, 색상 등)을 정한 뒤 **주문 → 결제**(카드·간편결제 또는 **무통장 입금**)합니다.
- **마이페이지**에서 주문 진행, 송장, 쿠폰·포인트, 배송지를 관리합니다.

### A.1.2 회원가입 (이메일)

| 단계 | 작업 | 기대 결과 |
|------|------|-----------|
| 1 | 상단 **로그인** → **회원가입** (`/register`) | 가입 폼 표시 |
| 2 | 이메일, 비밀번호, 이름, (선택) 휴대폰 입력 후 가입 | 가입 완료 안내 |
| 3 | 이메일 인증을 사용하는 경우 안내 메일의 링크 클릭 (`/verify-email`) | 인증 완료 후 로그인 가능 |

**사전 조건:** 유효한 이메일, 비밀번호 정책(사이트 안내) 충족.

**문제 해결**

- 「이미 가입된 이메일」 → 로그인 또는 비밀번호 찾기(`/forgot-password`) 사용.
- 비밀번호 재설정은 메일 링크(`/reset-password`)로 진행.

### A.1.3 로그인

| 방식 | 경로 | 비고 |
|------|------|------|
| 이메일·비밀번호 | `/login` | 로그인 후 원래 가려던 페이지(`?next=`)로 이동 |
| 카카오 / 구글 | 로그인 화면의 소셜 버튼 | 최초 연동 시 계정 생성 |
| 로그아웃 | 마이페이지·헤더 메뉴 | 세션 종료 |

**중요:** 아래 기능은 **로그인 후**에만 사용할 수 있습니다.

- AI 로고 생성(빌더)
- 큰 디자인 이미지를 서버에 저장(주문 JSON 용량 절감)
- 장바구니 일괄 주문, 위시리스트, 저장된 디자인, 포인트·쿠폰(회원)
- 체크아웃 페이지(`/checkout/...`) — **비로그인 시 로그인 화면으로 이동**

게스트(비회원)도 빌더에서 주문할 수 있으나, 주문 확인 단계에서 **이메일**을 반드시 입력해야 합니다.

## A.2 홈과 상품 찾기

### A.2.1 상단 메뉴(헤더)

| 메뉴 | 설명 |
|------|------|
| 로고 | 홈(`/`) |
| 카테고리(반팔티, 카라티, 기능성, 후드 등) | `/products/list/{카테고리}` |
| 전체 상품 | `/products/list` |
| 테마별 베스트 / 추천 디자인 | 홈 내 앵커 섹션 |
| 단체티 만들기 | 빌더 `/builder` |
| 2분 컷 템플릿 | `/templates` |
| 검색 | 상품명 검색 |
| 장바구니 | `/cart` |
| 로그인·마이페이지 | 회원 메뉴 |

푸터에는 **사이트 설정**에 등록된 회사명, 고객센터 이메일·전화, 무통장 계좌, 약관·개인정보 링크가 표시됩니다.

### A.2.2 상품 목록·상세

1. 카테고리 또는 목록에서 상품 카드를 클릭 → **상품 상세** (`/products/{상품주소}`).
2. 상세 페이지에서 확인할 내용:
   - 이미지 갤러리, 가격, 리뷰, 상품 설명·고시 정보
   - **커스텀 제작:** 상세 내 빌더 또는 「디자인하기」로 시안 편집
   - **기성품(READY_MADE):** 옵션·수량 선택 후 바로 장바구니/구매

### A.2.3 위시리스트(찜)

- 로그인 상태에서 상품 상세의 찜 버튼 사용.
- **마이페이지 → 찜** (`/mypage/wishlist`)에서 모음.

## A.3 커스텀 빌더로 시안 만들기

**경로:** `/builder` 또는 상품 상세에 포함된 빌더.

### A.3.1 화면 구성

| 영역 | 역할 |
|------|------|
| 중앙 캔버스 | 목업(티셔츠 등) 위에 로고·텍스트 배치 |
| 우측 **주문 패널** | 수량, 사이즈, 색·원단·인쇄면 등 옵션, 예상 금액, **주문하기** |
| 좌측 사이드바(펼침) | 주문 연결 후 **작업 요청(핀)**, **Comment** |
| 우측 플로팅 도구 | 상품 변경, 이미지 업로드, 텍스트, AI 디자인 |
| 상단 툴바 | 실행 취소/다시, 레이어, 확대·축소, 인쇄영역 표시, 객체 편집 |

**면(앞/뒤) 전환:** 캔버스 상단 또는 뷰 토글로 면을 바꿉니다. 면마다 디자인이 따로 저장됩니다.

### A.3.2 시안 편집 — 기본 순서

1. **상품·옵션** — 우측 패널에서 수량, 사이즈, 인쇄면(앞만/앞뒤 등), 색상 등 선택. 금액이 실시간 갱신됩니다.
2. **인쇄영역** — 「인쇄영역 표시」를 켜면 나염 가능 범위를 확인합니다. 로고는 이 안에 배치하는 것이 좋습니다.
3. **이미지** — 「이미지 업로드」 → PNG/JPG/WEBP 선택 → 캔버스에 배치 → 크기·회전(툴바).
4. **텍스트** — 「텍스트」 → 더블클릭으로 문구·글꼴·색 수정.
5. **AI 로고** — **로그인 필수.** 「AI 디자인」 → 문구·특징 입력 → 생성 → 원하는 시안 적용.
6. **저장(회원)** — 디자인 저장 기능 사용 시 마이페이지/다음 편집에 불러올 수 있습니다.

### A.3.3 주문하기(빌더에서)

1. 우측 패널 **주문하기** (또는 동일 역할 버튼).
2. **주문 확인 모달** — 받는 사람, 연락처, 주소(우편번호 검색), 요청사항 입력.
3. **비회원:** 이메일 필드 필수(주문 조회·안내용).
4. 확인 → 주문 생성 → **결제 페이지**(`/checkout/{주문ID}`)로 이동.

**주문 불러오기:** 기존 주문 번호로 빌더 상태를 불러와 수정할 수 있습니다(입금 전·운영 정책에 따름). 수정 후 「주문 업데이트」 흐름이 열립니다.

**신규 주문:** 불러온 주문이 있을 때 「신규 주문」은 현재 작업을 초기화합니다. 확인 대화상자에 주의.

### A.3.4 작업 요청(핀)과 코멘트

주문과 연결된 뒤 좌측 **작업 요청** 탭에서 캔버스에 핀을 달고 메모를 남길 수 있습니다. 제작 시 참고용입니다. **Comment** 탭은 주문 관련 대화(운영자와 공유되는 스레드)입니다.

### A.3.5 2분 컷 템플릿

`/templates`에서 미리 만들어진 템플릿을 선택해 빌더로 이어갈 수 있습니다. 행사·동아리용 빠른 시작에 적합합니다.

## A.4 주문·결제

### A.4.1 주문 경로 정리

| 경로 | 설명 |
|------|------|
| 빌더 → 주문 확인 | 커스텀 제작 |
| 상품 상세 | 기성품 즉시 구매 |
| 장바구니 → 주문 | 여러 기성품 (`/cart`) |

### A.4.2 결제 페이지 (`/checkout/{주문ID}`)

**로그인 필수.** 관리자 계정은 고객 결제 화면에 들어가지 않고 관리자 주문으로 이동합니다.

화면 구성:

1. **주문 요약** — 상품명, 상품금액, 배송비, 쿠폰·포인트 할인, **최종 결제 금액**
2. **쿠폰·포인트** — 코드 입력, 포인트 사용량 입력 → **할인 적용** (금액·토스 결제 UI가 다시 맞춰짐)
3. **결제 수단 선택**
   - **카드 · 간편결제 (토스페이먼츠)** — 결제 수단 UI 로드 후 **○○원 결제하기**
   - **무통장 입금** — 안내 계좌 확인 후 **무통장 입금으로 주문 확정**

#### 토스페이먼츠

- 테스트 모드일 때 화면 상단에 「테스트 모드」 안내가 보입니다(실제 청구 없음).
- 결제 성공 → `/checkout/success` → 승인 후 마이페이지 주문 상세로 확인.
- 실패 → `/checkout/fail` → 다시 결제하기 링크.

#### 무통장 입금

1. 결제 수단에서 **무통장 입금** 선택.
2. 표시된 **입금 계좌·예금주·입금액** 확인.
3. **입금자명:** 주문 시 입력한 **받는 사람 이름**과 동일하게.
4. **메모:** **주문번호**(예: JH-2026-0001) 기재 권장.
5. **무통장 입금으로 주문 확정** 클릭 → 마이페이지 주문 상세로 이동.
6. 주문 상태 **입금대기**, 결제 **미입금** — 운영자 입금 확인 후 **제작**이 시작됩니다.

「← 나중에 결제하기」로 주문 상세만 보고 나중에 같은 checkout URL로 재결제 가능(미결제인 경우).

### A.4.3 배송비·할인(참고)

- 상품·수량에 따라 단가 할인(대량)이 적용될 수 있습니다.
- 일정 금액 이상 **무료 배송** 정책이 있을 수 있습니다(주문 요약에 표시).
- 쿠폰·포인트는 **결제 직전** checkout에서 적용하는 것이 일반적입니다.

## A.5 마이페이지

**경로:** `/mypage` (로그인 필수, 관리자는 `/admin`으로 안내)

상단 탭:

| 탭 | 경로 | 용도 |
|----|------|------|
| 주문 내역 | `/mypage`, `/mypage/orders/{id}` | 진행 중·과거 주문, 결제하기, 취소 |
| 찜 | `/mypage/wishlist` | 위시리스트 |
| 쿠폰 | `/mypage/coupons` | 보유·등록 쿠폰 |
| 교환·반품 | `/mypage/returns` | 반품 신청 내역 |
| 1:1 문의 | `/inquiry` | 문의 작성 |
| 내 정보 | `/mypage/profile` | 이름, 비밀번호, 탈퇴 등 |
| 배송지 | `/mypage/addresses` | 배송지록 CRUD |

### A.5.1 주문 상세

- **주문번호, 상태, 결제 상태**, 배송지, 요청사항, 금액 breakdown.
- **미결제:** 「결제하기」 → checkout. 무통장 안내(계좌·입금자명).
- **송장번호** 등록 시 배송 조회 링크.
- **주문 취소:** `대기` 또는 `입금대기`이고 **아직 결제 완료 전**일 때만 가능. 결제 완료 후에는 고객센터 문의.

### A.5.2 쿠폰

- 마이페이지에서 쿠폰 코드 **등록**.
- **결제 화면**에서 코드 입력 후 「할인 적용」.

### A.5.3 배송지

- 여러 배송지 저장, 기본 배송지 설정.
- 주문 시 우편번호 **주소 검색**(다음 우편) 사용.

## A.6 비회원 주문·조회

### A.6.1 비회원 주문

- 빌더 등에서 **로그인 없이** 주문 가능(이메일 입력).
- 결제·마이페이지 전체 기능을 쓰려면 **회원가입** 또는 주문 후 부여되는 **게스트 세션**으로 로그인 상태가 될 수 있습니다(이메일 중복 시 「이미 가입된 이메일 → 로그인」 안내).

### A.6.2 비회원 주문조회

**경로:** `/orders`

| 입력 | 설명 |
|------|------|
| 주문번호 | 예: JH-2026-xxxx |
| 이메일 | 주문 시 입력한 이메일 |

조회 결과: 진행 상태, 결제·배송 요약. 회원이면 마이페이지 이용을 권장.

## A.7 문의·FAQ·챗봇

### A.7.1 FAQ

**경로:** `/faq` — 제작 기간, 배송, 교환·반품, 송장, 비회원 조회 등.

### A.7.2 1:1 문의

**경로:** `/inquiry` — 제목·내용 작성. 로그인 시 정보 자동 연동될 수 있음.

### A.7.3 챗봇(우하단)

- **말풍선 아이콘**으로 열기.
- FAQ 기반 자동 답변, **주문번호·이메일**로 조회 안내, 마이페이지·문의 링크 제공.
- 대화 스레드는 브라우저에 저장(기기 변경 시 이력 없음).

---

## A.8 교환·반품

- **정책 페이지:** `/returns` — 주문제작 상품은 제작 착수 후 교환·반품이 제한될 수 있음.
- **신청:** 마이페이지 **교환·반품** — eligible 주문에 대해 사유·내용 제출.
- 처리 상태는 마이페이지에서 확인. 긴급 시 1:1 문의 또는 고객센터 연락.

## A.9 자주 묻는 문제 (고객)

| 증상 | 조치 |
|------|------|
| AI 로고가 안 됨 | 로그인 여부 확인. OPENAI 미설정 시 사이트 안내 문구 표시 — 운영자 문의 |

## B.3 주문·결제 처리

**경로:** `/admin/orders`

### B.3.1 주문 목록

- 필터·검색으로 주문번호, 고객, 상태별 조회.
- **주문 상태**와 **결제 상태** 뱃지 확인.

### B.3.2 주문 상세에서 할 일

| 상황 | 운영 작업 |
|------|-----------|
| 무통장 **미입금** | 고객 입금 확인 후 결제 상태 **입금완료(PAID)**, 필요 시 주문 상태 **확인됨(CONFIRMED)** |
| 토스 **결제 완료** | 자동 PAID — 제작 단계로 진행 |
| **제작** | 상태 **제작 중(IN_PRODUCTION)** |
| **출고** | **배송 중(SHIPPED)** + **송장번호** 입력 |
| **완료** | **배송 완료(DELIVERED)** |

- **작업용 아트워크·빌더 JSON** 다운로드/미리보기 기능(패널)으로 생산팀 전달.
- 필요 시 **관리자 빌더** 링크로 시안 수정(`from=admin` 등).

### B.3.3 환불

- 토스 결제 환불은 **환불 API·PG 연동** 상태에 따름(미완 시 수동 처리·메모).
- `/admin/orders` 상세 또는 refund API 경로 — 운영 정책에 맞게 사용.

### B.3.4 고객 주문 취소

- 고객은 **입금대기·대기**만 취소 가능.
- **제작 시작 후** 취소는 관리자 판단·CS 협의.

## B.5 상품·카탈로그 운영

### B.5.1 카테고리

**`/admin/categories`** — slug, 노출 순서, 이름(반팔티, 카라티 등). 헤더 네비와 연동.

### B.5.2 상품

**`/admin/products`**

- **등록·수정:** 이름, slug, 카테고리, 판매 유형(**CUSTOM** / **READY_MADE**), 빌더 타입, 가격·옵션 스키마, 재고(기성품), 노출 플래그(베스트, 신상 등).

- **상세 콘텐츠:** `/admin/products/{id}/content` — 상세 하단 섹션(스토리, FAQ 블록 등).

**이미지 업로드:** 관리자 업로드 API — **파일당 8MB**, PNG/JPG/WEBP → `/uploads/mockups/...` URL 자동 부여.

# 부록: 주문·결제 상태

### 주문 상태 (Order)

| 코드 | 화면 라벨 | 의미 |
|------|-----------|------|
| PENDING | 대기 | 초기 |
| AWAITING_PAYMENT | 입금대기 | 결제·입금 대기 |
| CONFIRMED | 확인됨 | 결제 확인·접수 |
| IN_PRODUCTION | 제작 중 | 나염·가공 진행 |
| SHIPPED | 배송 중 | 출고·송장 |
| DELIVERED | 배송 완료 | 종료 |
| CANCELLED | 취소 | 취소됨 |

### 결제 상태 (Payment)

| 코드 | 라벨 |
|------|------|
| UNPAID | 미입금 |
| PAID | 입금완료 |
| REFUNDED | 환불 |
| FAILED | 실패 |

### 결제 수단

- **카드·간편결제:** 토스페이먼츠
- **무통장:** BANK_TRANSFER — 관리자 입금 확인 전까지 UNPAID
