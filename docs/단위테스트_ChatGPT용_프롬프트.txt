========================================
ChatGPT에 보낼 것 (순서)
========================================
1) 엑셀 양식 파일 업로드 (단위테스트 결과서.xlsx 등)
2) 아래 [지시문] 전체 붙여넣기
3) [시나리오 목록] 전체 붙여넣기 (또는 이 파일 통째로)

========================================
[지시문] — 여기부터 복사
========================================

업로드한 **단위테스트 결과서** 엑셀 양식과 **아래 시나리오 목록**을 기준으로, 시나리오 **한 건당 엑셀 1행**이 되도록 내용을 채워 주세요.

## 출력 형식
- **마크다운 표·서론·결론 금지.**
- **엑셀에 붙여넣기용**: 첫 줄은 아래 **헤더 12개**(탭으로 구분), 2행부터 데이터.
- 시나리오 목록에 있는 **모든 행**을 빠짐없이 작성.
- **테스트 결과**, **결과코멘트**, **삭제/수정 여부** 3열은 **비워 두기** (사람이 채움).

## 헤더 (탭 구분, 엑셀 양식과 동일)
테스트구분	시스템	서비스명	시나리오 ID	시나리오명	수행내역	사전준비	테스트데이터	예상결과	테스트 결과	결과코멘트	삭제/수정 여부

## 고정값
- **테스트구분**: 모든 행 `단위테스트`
- **시스템**: 모든 행 `운영` (또는 `대지나염 쇼핑몰`)

## 작성 규칙
- **시나리오 ID**: 목록에 적힌 ID 그대로 사용 (변경 금지).
- **수행내역**: 1) 2) 3) 번호 단계로, API면 HTTP 메서드·URL 포함.
- **사전준비**: 로그인 여부, DB 데이터, 상품 타입(CUSTOM/READYMADE) 등.
- **테스트데이터**: 구체 값 (JSON 키, 수량, slug, email 등).
- **예상결과**: HTTP 코드, DB 상태, 화면·금액 수치까지 구체적으로.
- 목록에 없는 시나리오 **추가하지 말 것**. 목록만 100% 채울 것.

지시를 이해했으면, **헤더 1줄 + 데이터 전체**만 탭 구분으로 출력하세요.
